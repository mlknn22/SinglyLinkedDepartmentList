Это учебная консольная программа на языке C++, предназначенная для хранения и управления информацией о кафедрах вуза с использованием односвязного списка.
Функционал программы:
1) вывод меню для работы со списком;
2) вывод всех кафедр;
3) добавление кафедры в начало списка;
4) добавление кафедры в конец списка;
5) добавление кафедры после определенной кафедры;
6) добавление кафедры перед определенной кафедрой;
7) удаление кафедры из списка;
8) по запросу выдаются сведения о кафедрах определенного корпуса.
9) по запросу выдаются сведения о кафедрах в диапазоне введенных
пользователем аудиторий;
10) по запросу выдаются сведения о кафедре с максимальным
количеством преподавателей;
11) сохранение данных списка в бинарный файл;
12) извлечение данных из бинарного файла и помещение новых кафедр в
список.
